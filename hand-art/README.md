# Hand Flow Art

손가락 움직임으로 흐르는 디지털 유체 아트. 손 인식 AI(Google MediaPipe Hands, 경량 모델)가 파일 안에 함께 들어 있어 인터넷 없이 폰에서 돌아갑니다.

## 구성 (약 19MB)
- `index.html` — 유체 시뮬레이션(WebGL2) + 부조 조명 + 점묘 입자 렌더 + 손 제스처
- `mediapipe/` — 손 인식 AI 런타임(WASM)과 모델 (`hand_landmark_lite.tflite` 2MB, 손바닥 검출 모델은 `.data`에 포함)
- `sw.js`, `manifest.json`, `icons/` — 오프라인 설치(PWA)

## 폰에 올리기 (APK 없이)
1. GitHub 새 저장소에 이 폴더 내용을 그대로 업로드 → Settings › Pages › main 브랜치 활성화
2. 폰 Chrome으로 `https://<아이디>.github.io/<저장소>/` 접속 (카메라는 HTTPS에서만 동작)
3. 상태 문구가 "오프라인 저장 완료"로 바뀌면 AI 모델까지 폰에 저장된 것
4. 하단 "앱 설치" 버튼 또는 Chrome 메뉴 › 홈 화면에 추가 → 이후 비행기 모드에서도 실행

## 조작
- 손가락 5개: 각자 다른 색으로 흐름을 그림 (검지가 가장 강함)
- 검지만 펴기: 가리킨 방향으로 물감이 계속 뿜어져 나감 (손가락 방향을 바꾸면 흐름 방향도 바뀜)
- 엄지+검지 집기: 색 폭발 + 소용돌이 (왼손/오른손 회전 방향 반대)
- 주먹: 흐름이 멈추고 굳음 (부조가 더 깊어짐) · 손을 펴면 다시 흐름
- 화면 터치 드래그도 동일하게 그림
- 메뉴: 평소엔 숨김 · 화면 아래 바를 위로 밀면(또는 탭) 열림, 아래로 밀거나 그림을 탭하면 닫힘
- 아래 바 색: 회색 = 손 미인식, 흰색 = 카메라가 손을 인식 중 (카메라 화면은 띄우지 않음)

## 수정 후 업데이트
`sw.js`의 `CACHE = 'hand-flow-v1'` 숫자를 올리면 폰의 캐시가 새 버전으로 교체됩니다.
