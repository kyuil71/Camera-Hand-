# Hand Flow Art

손가락 움직임으로 흐르는 디지털 유체 아트. 손 인식 AI(Google MediaPipe Hands, 경량 모델)가 파일 안에 함께 들어 있어 인터넷 없이 폰에서 돌아갑니다.

## 구성 (약 19MB)
- `index.html` — 유체 시뮬레이션(WebGL2) + 부조 조명 + 점묘 입자 렌더 + 손 제스처
- `mediapipe/` — 손 인식 AI 런타임(WASM)과 모델 (`hand_landmark_lite.tflite` 2MB, 손바닥 검출 모델은 `.data`에 포함)
- `sw.js`, `manifest.json`, `icons/` — 오프라인 설치(PWA)

## 폰에 올리기 (APK 없이)
1. GitHub 새 저장소에 이 폴더 내용을 그대로 업로드 → Settings › Pages › main 브랜치 활성화
2. 폰 Chrome으로 `https://<아이디>.github.io/<저장소>/` 접속 (카메라는 HTTPS에서만 동작)
3. 상태 문구가 "오프라인 저장 완료"로 바뀌면 AI 모델까지 폰에 저장된 것
4. 하단 "앱 설치" 버튼 또는 Chrome 메뉴 › 홈 화면에 추가 → 이후 비행기 모드에서도 실행

## 모드
- Pigment(물감): 큰 덩어리 중심으로 흐르는 고채도 유체 물감 (팔레트: Neon / Cyber / Synthwave / Tropical / Dream)
- Aurora(빛): 어두운 배경 위로 빛 입자 물결이 흐르는 디지털 아트. 손가락(제스처·터치)이 나타날 때마다 새 색의 빛이 뿜어져 나와 자기 흐름(소용돌이)을 만들고, 다른 빛을 밀어내고 부딪히고 섞이다가 몇 초 뒤 희미하게 사라짐 (색: 다채로움 / 초록 / 노랑 / 하양 / 파랑)
- Silk(실크): 여러 겹의 반투명 실크 리본이 공중·물속에서 천천히 춤추듯 흐름 — 비틀림·주름·은은한 광택·관성 (팔레트: Pastel / Pearl / Ocean / Sunset / Aurora, 색은 아주 천천히 변화)
- Cloud(구름): 생성→확산→변형→합쳐짐→흩어짐을 반복하는 3겹 구름·안개 (Mist / Dream Cloud / Twilight / Moonlight — 색·밀도·속도·질감이 스타일마다 다름). 손이 지나간 자리는 부드럽게 갈라졌다가 다시 합쳐짐
- Ripple(물): 맑은 호수 — 파동 방정식 물결, 굴절(1.333)로 보이는 자갈 바닥, 프레넬 하늘 반사, 깊이별 빛 흡수, 바닥 코스틱
- Ripple · 퐁당: 손가락이 닿는 순간마다 손끝만 한 물이 눌려 바닥이 볼록렌즈처럼 일렁이고 큰 물결 하나가 퍼짐(여러 손가락 = 각자 1개, 동시에 여러 개면 각각 조금 부드럽게). 누르고 있으면 추가 파동 없음, 누른 채 움직이면 물이 밀려나며 넓게 퍼지는 물결. 카메라: 손이 보이는 상태에서 손가락을 구부리면 구부린 손끝 위치마다 퐁당(하나 구부리면 1개, 여러 개 동시에 구부리면 동시에 여러 개, 엄지 포함). 손이 처음 보일 때나 펼 때는 퐁당 없음. 주먹은 1초 가까이 쥐고 있어야 물이 멈춤, 검지 하나를 펴면 손끝이 물에 닿은 상태
- Ripple · 퐁당 크기: 메뉴의 '퐁당 크기' 슬라이더로 터치·손가락 퐁당이 퍼지는 크기를 0.5배~2배로 조절 (가운데 = 기본)
- Ripple · 세기 상한: 여러 손가락으로 마구 퐁당·휘저어도 동시에 퐁당 3번 정도 이상으로는 거칠어지지 않음(넘치는 힘은 부드럽게 줄고, 거친 물은 더 빨리 가라앉음) → 바닥 빛 무늬가 항상 보임
- Ink(먹): 구겨진 결·섬유·거친 펄프 질감이 있는 한지 위에 먹물이 스며드는 모드. 터치·손가락이 지나가면 물기가 한지 섬유를 타고 번지며 먹을 실어 나르고, 물이 얇아지는 가장자리에서 먹이 내려앉아 또렷하고 들쭉날쭉한 경계와 가는 실핏줄 무늬가 생김. 한 번 지나간 곳은 옅게, 여러 번 겹친 곳은 짙게 쌓이고, 먹은 스며든 뒤 약 6초에 걸쳐 옅어져 사라짐. 가끔 저절로 먹 한 방울이 떨어짐. 먹 옵션: 랜덤(붓이 검은 먹으로 크고 길게 과감한 획을 스스로 그림 — 보다가 언제든 함께 그릴 수 있음, 기본값) / 먹(검정) / 선명(채도 높은 컬러) / 차분(채도 낮은 컬러) / 파스텔. 흔들기를 켜면 기울인 쪽으로 더 번짐
- Wave(파도): 휴대폰 화면이 사방이 막힌 수족관. 바닷가 모래 바닥 위 얕은 물이 얕은물 방정식으로 움직임. 폰을 기울이면 물이 낮은 쪽으로 쏠려 모래가 드러나고, 벽에 부딪히면 하얀 거품과 물보라가 튐. 흔들면 물이 뒤늦게 따라오며 출렁임. 터치·손은 물을 밀고, 톡 치면 물결. 이 모드를 고르면 흔들기(움직임 센서)가 자동으로 켜짐
- Ripple · 비: 비 없음 / 이슬비 / 비 / 소나기 — 빗방울마다 가는 동심원 물결 묶음이 퍼지고 겹치며, 비가 셀수록 수면 전체가 거칠어짐 (큰 빗방울은 굵은 물결도 일으킴)
- 물 · 손 담그기: 켜면 손이 물에 들어간 것처럼 수면이 푹 꺼지고 둘레로 물결 (손 모양은 나오지 않음). 터치는 누르는 시간, 손은 손바닥을 화면 쪽으로 내민 시간만큼 깊이 들어가고, 떼면 패인 물이 차오르며 물결이 퍼짐
- 물 바닥: 검은 유리(기본) / 다크 그레이 / 그레이 타일(큼직한 격자, 화면에 약 20칸) / 자갈
- 두 모드 모두 화면 상하좌우 끝이 벽: 부딪히면 솟아오르고, 벽을 타고 퍼지고 되튕겨 출렁임 (물은 흰 물보라)
- 음악: 물감 모드는 audio/where_the_stream_widens.mp3, 물 모드는 audio/glass_upon_the_lake.mp3, 빛 모드는 audio/where_the_ocean_meets_sky.mp3 반복 재생(모드 전환 시 부드럽게 바뀜), 손 움직임이 빨라지면 템포가 최대 1.45배까지 빨라지고 잔잔해지면 원래 속도로 (음 높이는 유지)

## 음악 인터랙션 (Music Interaction)
메뉴의 스위치(기본 OFF). ON이면 손 인식 결과를 그대로 받아 Web Audio로 배경 음악에 효과를 줌 — 그래픽 반응은 그대로 동시에 동작.
- 손 높이 → 음량 60~100% (기존 음량 기준 상대값)
- 손 좌우 → 스테레오 팬 -0.5~+0.5
- 손 속도 → 로우패스 필터 약 5.5 kHz(느림, 따뜻함) ~ 18 kHz(빠름, 선명함)
- 엄지+검지 집기 → 리버브 최대 22%
- 손이 사라지면 약 2초에 걸쳐 원래 소리로 복귀. ON일 때는 재생 속도·음정을 바꾸지 않음(OFF일 때는 기존처럼 손 속도에 따라 템포 변화)
- 구조: bgm(HTMLAudioElement) → MediaElementSource(1회) → Lowpass → StereoPanner → Dry/(Convolver→Wet) → Gain → 출력

## 녹화 · 캡처
- 오른쪽 위 ● 버튼: 누르면 녹화 시작(옆에 경과 시간), 다시 누르면 멈추고 MP4로 저장 (음악이 켜져 있으면 소리도 함께). MP4를 지원하지 않는 브라우저에서는 WebM으로 저장
- 오른쪽 위 카메라 버튼: 지금 화면을 JPEG로 저장
- 저장되는 영상·이미지에는 작품 화면만 담기고 버튼과 아래 메뉴는 나오지 않음

## 조작
- 손가락 5개: 각자 다른 색으로 흐름을 그림 (검지가 가장 강함)
- 검지만 펴기: 가리킨 방향으로 물감이 계속 뿜어져 나감 (손가락 방향을 바꾸면 흐름 방향도 바뀜)
- 엄지+검지 집기: 색 폭발 + 소용돌이 (왼손/오른손 회전 방향 반대)
- 주먹: 흐름이 멈추고 굳음 (부조가 더 깊어짐) · 손을 펴면 다시 흐름
- 화면 터치 드래그도 동일하게 그림
- 흐름 속도: 메뉴의 슬라이더로 기본 속도 조절(기본값 아주 느림). 손가락을 빠르게 움직이면 화면 전체 흐름이 빨라지고, 느려지거나 멈추면 기본 속도로 서서히 돌아옴
- 메뉴: 평소엔 숨김 · 화면 아래 바를 위로 밀면(또는 탭) 열림, 아래로 밀거나 그림을 탭하면 닫힘
- 아래 바 색: 회색 = 손 미인식, 흰색 = 카메라가 손을 인식 중 (카메라 화면은 띄우지 않음)
